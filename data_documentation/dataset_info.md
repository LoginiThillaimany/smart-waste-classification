## Why This Dataset?

This dataset was selected for the following reasons:

1. **Sufficient complexity** — 12 original classes with ~15,150 images provide enough data for training deep-learning models without being trivially small.
2. **Real-world relevance** — Waste classification is a genuine environmental problem; automating it supports recycling and sustainability efforts.
3. **Not from a lecture/lab exercise** — This dataset is not part of any SE4050 module material; it is an independent Kaggle dataset collected via web scraping.
4. **Multi-class challenge** — Consolidating 12 source classes into 6 target classes introduces a non-trivial class-mapping decision and potential class-imbalance issues, which add analytical depth.
5. **Compatible with transfer learning** — Images are colour photographs of everyday objects, making them suitable for both custom CNN and pretrained ImageNet-based architectures.

## Class Mapping

The original 12 classes are consolidated into 6 target classes to align with standard municipal waste-sorting categories.

| Target class | Source folder(s) | Rationale |
|---|---|---|
| Plastic | `plastic` | Direct mapping — plastic bottles, containers, packaging |
| Paper_Cardboard | `paper`, `cardboard` | Both are cellulose-based recyclables processed together in most facilities |
| Metal | `metal` | Direct mapping — aluminium and steel/tin cans |
| Glass | `brown-glass`, `green-glass`, `white-glass` | All three are glass variants differing only in colour; recycling process is identical |
| Organic | `biological` | Biodegradable kitchen and food waste |
| Residual | `trash`, `clothes`, `shoes`, `battery` | Non-recyclable or hazardous items that do not fit the above categories |

## Access Instructions (for reproducibility)

```bash
# 1. Install the Kaggle CLI (already in requirements.txt)
pip install kaggle

# 2. Place your kaggle.json API token in the correct location:
#    - Windows: %USERPROFILE%\.kaggle\kaggle.json
#    - Linux/macOS: ~/.kaggle/kaggle.json

# 3. Download the dataset
kaggle datasets download -d mostafaabla/garbage-classification

# 4. Unzip into the data/raw/ directory
#    Windows (PowerShell):
Expand-Archive garbage-classification.zip -DestinationPath data/raw/
#    Linux/macOS:
#    unzip garbage-classification.zip -d data/raw/

# 5. Consolidate into 6 target classes
python preprocessing/preprocess.py --remap

# 6. Create the fixed train/val/test split
python preprocessing/preprocess.py --split
```

## Fixed Split Configuration

| Parameter | Value |
|---|---|
| Random seed | 42 |
| Train ratio | 0.70 |
| Validation ratio | 0.15 |
| Test ratio | 0.15 |
| Split script | `preprocessing/preprocess.py` |

**Important:** This split is generated once and shared across all four models. Do not regenerate it independently — doing so risks data leakage and breaks fair comparison between models.
